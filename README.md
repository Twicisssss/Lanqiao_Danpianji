# 蓝桥杯单片机赛道备赛资料

第十六届蓝桥杯嵌入式设计与开发（单片机赛道）备赛代码与资料，基于 **CT107D 开发板**（STC15F2K60S2）。

## 目录结构

### `00_DP2025_SCM` — 官方资料包

| 内容 | 说明 |
|------|------|
| `BSP/` | 官方底层驱动源码（ds1302、iic、onewire） |
| `Datasheet/` | 芯片数据手册（AT24C02、DS1302、DS18B20、PCF8591 等） |
| `Tools/` | 开发工具（STC-ISP、CH34x 驱动、VS Code、串口调试助手） |
| `SCH_V31.pdf` / `SCH_V40.pdf` | CT107D 开发板原理图 |
| `STC15_DS.pdf` | STC15 系列数据手册 |

### `01_modules` — 单独模块代码

针对各外设模块的独立练习工程：

- **AT24C02** — I2C EEPROM 读写
- **DS1302** — 实时时钟
- **DS18B20** — 温度传感器（单总线）
- **NE555** — 频率测量
- **PCF8591** — ADC/DAC 转换
- **UltraSound** — 超声波测距
- **Usart** — 串口通信

### `02_frameworkA` — 非调度器框架

包含 **27 套真题/模拟题代码** 和非调度器模板，覆盖第 11~16 届省赛、国赛及 4T 积分赛题。另附第 8~15 届省赛原题（`省赛练习_有题目/`）。

代码结构采用 `Driver/` + `User/` 分层，每套题均为 Keil uVision 工程。

### `03_frameworkB` — 调度器框架

包含 **6 套真题代码** 和调度器模板（含串口/无串口两个版本），覆盖第 13~15 届省赛、国赛。

代码结构采用 `Source/` + `Project/` 分层，基于简易任务调度器实现多任务管理。

## 开发环境

- **IDE**: Keil uVision5（C51）
- **烧录工具**: STC-ISP
- **开发板**: CT107D（V3.1 / V4.0）
- **芯片**: STC15F2K60S2

## 涉及外设

DS18B20 | DS1302 | AT24C02 | PCF8591 | NE555 | 超声波模块 | 串口 | LED | 数码管 | 矩阵键盘 | 独立按键 | 继电器 | 蜂鸣器 | DAC 输出

## 使用说明

1. 使用 Keil uVision5 打开 `.uvproj` 工程文件
2. 编译生成 `.hex` 文件
3. 使用 STC-ISP 将 `.hex` 烧录至开发板
